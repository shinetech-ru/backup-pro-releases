# BackUp PRO

**Бесплатное резервное копирование и восстановление файлов для Windows 10 и 11.**

BackUp PRO — настольное приложение от ShineTech для выборочного резервного копирования папок и файлов на локальные диски, сетевые хранилища и облака. Программа работает по профилям: для каждого профиля можно задать свои источники, расписание, приёмники и уведомления.

## Возможности

- **Источники:** локальные папки и файлы, UNC-пути `\\server\share`, подключённые сетевые диски.
- **Приёмники:** локальный диск, FTP/FTPS, SFTP, WebDAV, Облако Mail.ru, Облако Билайн, Google Drive и Яндекс Диск API (OAuth).
- **Режимы:** копирование как есть или архив ZIP/7z.
- **Шифрование:** AES-256 для архивов с паролем.
- **Инкрементальные копии:** после первого полного бэкапа сохраняются только изменения.
- **Несколько приёмников:** одна операция может писать в несколько мест одновременно.
- **Расписание:** ежедневно, по дням недели, числам, чётности или конкретным датам.
- **Восстановление:** выбор файлов и папок, в выбранную папку или на исходное место.
- **Проверка:** SHA-256 для восстановленных файлов; страховочные копии перед перезаписью.
- **Уведомления:** Telegram и SMTP — все события или только ошибки.
- **Интерфейс:** русский и английский языки, светлая и тёмная темы, работа в трее.
- **Трей:** «Скрыть/Показать», «Настройки», «Выход».
- **Резервная копия настроек:** защищённый экспорт/импорт профилей, подключений, каналов и секретов в `.stbpset`.
- **Только по маске:** можно сохранять исключения или включать только выбранные типы файлов.
- **Обновления:** автоматическая проверка и кнопка установки в настройках.

## Большие архивы

Для больших архивов в облака рекомендуется разбивать архив на части по **512 МБ**. Яндекс Диск не подходит для передачи больших архивов, особенно зашифрованных: API ограничивает скорость и месячный объём загрузки.

## Системные требования

- Windows 10 22H2 или Windows 11, x64;
- установленный .NET Runtime не обязателен — используется self-contained сборка;
- около 173 МБ на диске для установленной программы (без пользовательских данных).
